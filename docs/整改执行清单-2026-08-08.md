## §5 剔除清单（暂不做，附理由）

| 项 | 理由 |
|---|---|
| U15 波形/倍速/收藏（整批） | 重实现投入大，仅保留 60s 自动停（B1-12） |
| U23 抽 12 组件收敛 454 处内联 style | 全面重构回归风险高，违背最小改动原则 |
| U24 圆角 token 收敛（实测 28 处） | 纯视觉项，用户无感知 |
| U27 匹配/礼物动效 | 装饰性，产品验证期不做 |
| U28 PWA 多尺寸图标 | 若近期推安装再提前；否则剔除 |
| U29 reduced-motion/focus-visible | 无障碍项，公测期后排 |
| U30 WebPush | 依赖 BK6，iOS 仅 PWA 支持，等用户量起来 |
| U31-U34 chunk拆分/虚拟滚动/BroadcastChannel/A2HS | 文档自标可选；引入构建管线是大工程，等性能实测痛点再立项 |
